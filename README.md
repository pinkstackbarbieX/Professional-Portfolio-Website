# Siyahluma "Seya" Kobese — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my background, skills, projects, and experience as a Digital Learning Specialist, Administrative Professional, and self-directed developer.

## About This Project

This portfolio was built as part of a personal branding project, with the goal of creating a site I can confidently share with potential employers when applying for internships and job opportunities. AI tools (Claude) assisted in the development process, and I directed, reviewed, and understand every design and content decision in the final result.

## Sections

- **Home** — professional introduction and quick facts
- **About Me** — background and personal statement
- **Skills** — technical, cybersecurity, digital marketing, education, administration, AI tools, and languages
- **Projects** — four self-directed builds with tech stacks
- **Experience** — a full work history timeline
- **Education** — Matric and current coursework
- **Certifications** — Cisco, TryHackMe, TEFL/TESOL, NEMISA, and more
- **Leadership & Achievements** — debate, sport, and academic recognition
- **Contact** — email, phone, GitHub, and a downloadable CV

## Built With

- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript
- Google Fonts (Fredoka, Quicksand, Space Mono)
